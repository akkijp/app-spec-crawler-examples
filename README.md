# app-spec-crawler — sample output

Sample documents produced by [app-spec-crawler](https://github.com/akkijp/app-spec-crawler-skill), a Claude Code skill that crawls a web app you are logged into (read-only) and writes a screen spec with screenshots.

**Browse it: https://akkijp.github.io/app-spec-crawler-examples/**

| Sample | Screens | Spec items | Crawl time |
|---|---|---|---|
| [WordPress admin](https://akkijp.github.io/app-spec-crawler-examples/wordpress/guide.html) | 50 | 376 | 8 min 46 s |

The WordPress site is a throwaway local install with fictional content. Nothing in the documents was written by hand; the per-screen descriptions were written by Claude from the screenshots, and the system guide by `claude -p`.
