About this screen

Purpose

Lets an administrator find and install a new plugin without leaving the admin. It is "Plugins" > "Add Plugin" in the side menu and the parent of the tabs p040–p044.

Shown when

Opened from "Plugins" > "Add Plugin" or the "Add Plugin" button on p013 Plugins. The plugin cards come from WordPress.org, so the list probably needs an internet connection. Shown to the logged-in user "demo" (an Administrator); whether lower roles can open it was not captured.

Who uses it and how

A site administrator looking for a plugin: browse the tabs, search by keyword, read "More Details", then press "Install Now".

Main features

  • Browse featured plugins from the WordPress Plugin Directory
  • Switch to popular, recommended and favorite lists
  • Search the directory by keyword, author or tag
  • Browse by popular tag
  • Install a plugin with "Install Now"
  • Upload a plugin .zip file

Usage flow

  1. Open "Plugins" > "Add Plugin".
  2. Browse the featured cards, switch tabs, or type into "Search Plugins".
  3. Click "More Details" to read about a plugin.
  4. Press "Install Now", then activate the plugin (inferred).
  5. Alternatively press "Upload Plugin" to install from a .zip file.

Variants and business rules

States and variants

Captured on the default "Featured" tab with 8 cards. Loading and error states (for example when WordPress.org cannot be reached) were not captured. No pagination is shown on this tab.

Business rules and constraints

The featured list is supplied by WordPress.org and changes over time, so the 8 plugins shown are a snapshot. Installing is probably limited to administrators.

Open questions

  • What does the screen show when WordPress.org cannot be reached?
  • Is the featured list fixed at 8 plugins, or was it limited by the directory at capture time?
