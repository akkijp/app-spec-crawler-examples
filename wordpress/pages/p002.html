About this screen

Purpose

The single place to check and apply software updates for the site, reached from the "Dashboard" menu group.

Shown when

Shown when "Dashboard" > "Updates" is chosen in the side menu (/wp-admin/update-core.php). Probably available only to users allowed to update the site.

Who uses it and how

Site administrators visit it to confirm the site is current, trigger a fresh check, or change how automatic updates are applied.

Main features

  • Current WordPress version and last update-check time
  • Manual re-check of available updates
  • Switching the automatic-update policy
  • Re-installing the current WordPress version
  • Update status for plugins and themes

Usage flow

  1. Open "Dashboard" > "Updates".
  2. Read the current version and the three status messages (WordPress, Plugins, Themes).
  3. If the check looks stale, press "Check again."
  4. When updates are listed, apply them from the relevant section (not observable on this site).

Variants and business rules

States and variants

Only the all-up-to-date state was captured. When updates are available the side menu and the sections probably show counts and update lists with checkboxes and update buttons. No "Screen Options" tab is present on this screen, only "Help".

Business rules and constraints

Automatic updates for every new WordPress version are enabled on this site, as stated on screen. Core, plugin and theme updates are reported separately.

Open questions

  • What the Plugins and Themes sections look like when updates are available.
  • Whether re-installing asks for confirmation before it starts.
  • Which roles can open this screen.
