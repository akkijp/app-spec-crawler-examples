About this screen

Purpose

Lets the administrator look up how the installation is configured and hand that information to a support engineer or a theme/plugin developer without giving them access to the site.

Shown when

Shown when the "Info" tab of "Site Health" is chosen (the address carries tab=debug). All sections start collapsed. Probably limited to administrators.

Who uses it and how

The administrator opens it when troubleshooting or when asked by support for environment details, expands the relevant section, or presses "Copy site info to clipboard" and pastes the result into a message.

Main features

  • Configuration reference in 10 collapsible sections
  • One-press copy of all site information to the clipboard
  • Counts of inactive themes and inactive plugins in the section titles
  • Overall health verdict shown at the top

Usage flow

  1. Open "Tools" → "Site Health" and choose the "Info" tab.
  2. Expand the section that covers the question (for example "Database" or "Filesystem Permissions").
  3. Or press "Copy site info to clipboard" and paste the text into a support message.
  4. Return to "Status" to see which items need fixing.

Variants and business rules

States and variants

Only the all-collapsed state was captured. Expanded sections, and any confirmation shown after copying, were not captured. The counts in the section titles depend on what is installed.

Business rules and constraints

The sections cover, in order: the WordPress installation itself, storage use, the active and inactive themes, inactive plugins, image handling, the server environment, the database, constants defined for WordPress, and whether WordPress can write to its folders. No "Active Plugins" or "Must Use Plugins" section appears, which suggests this site has no active plugin and no must-use plugin.

Open questions

  • Which items does each section contain when expanded?
  • Does the copied text include private values such as paths or database details, or are they masked?
  • Is a confirmation shown after "Copy site info to clipboard" is pressed?
  • Does an "Active Plugins" section appear once a plugin is activated?
