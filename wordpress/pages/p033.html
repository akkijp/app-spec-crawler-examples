About this screen

Purpose

Tells the people running the site what changed in the version they are on. It is information about the software, not about the content of Acme Journal.

Shown when

Shown to any logged-in user who opens it from the WordPress logo menu in the toolbar ("About WordPress") or from another About tab; the side menu has no item for it, so no menu entry is highlighted. WordPress probably also opens it automatically after a version update.

Who uses it and how

Any administrator or editor of the site who wants background on the WordPress software itself; it is read once in a while, not used in daily work.

Main features

  • Installed version shown in the banner
  • List of maintenance and security releases with release-note links
  • Illustrated overview of new features
  • Links to release notes, the field guide and learning resources
  • Tab bar to the other About WordPress pages

Usage flow

  1. Open "About WordPress" from the WordPress logo in the toolbar.
  2. Read the maintenance release list and the feature overview.
  3. Follow the release notes or field guide links for details, or switch tabs to the other About pages.
  4. Use "Go to Dashboard → Home" to return to work.
