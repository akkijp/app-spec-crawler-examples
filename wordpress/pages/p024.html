About this screen

Purpose

Lets an administrator read or change plugin source code directly on the server, as an emergency or learning tool. It is the last item under "Tools" in the side menu.

Shown when

Opened from "Tools" > "Plugin File Editor". The "Heads up!" dialog covers the editor on arrival. Shown to the logged-in user "demo" (an Administrator); whether lower roles can open it was not captured.

Who uses it and how

An administrator with PHP knowledge making a small fix or looking at how a plugin works; the warning advises against routine use.

Main features

  • View plugin source files with syntax highlighting
  • Switch between installed plugins
  • Browse a plugin's files and folders
  • Look up documentation for functions used in the file
  • Save changes with "Update File"

Usage flow

  1. Open "Tools" > "Plugin File Editor".
  2. Read the "Heads up!" warning and press "I understand" (or "Go back" to leave).
  3. Choose a plugin in "Select plugin to edit:" and press "Select".
  4. Pick a file in "Plugin Files".
  5. Edit the code and press "Update File".

Variants and business rules

States and variants

Captured only with the warning dialog open, so the editor is seen dimmed. The state after "I understand", the save result, a save error and editing an active plugin were not captured. The side menu shows "Site Health 2" with a badge on this screen.

Business rules and constraints

Direct edits may be lost on the next plugin update, as the dialog text says. The "(inactive)" marker in the subheading reflects the plugin's status on p013 Plugins.

Open questions

  • Is the warning shown on every visit or only once per user?
  • Is an extra warning shown when the plugin being edited is active?
  • Can file editing be switched off by site configuration?
