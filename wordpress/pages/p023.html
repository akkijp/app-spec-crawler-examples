About this screen

Purpose

Allows direct edits to theme source files from the browser; an advanced, risky tool placed under "Tools".

Shown when

Shown when "Tools" > "Theme File Editor" is chosen in the side menu (/wp-admin/theme-editor.php). The "Heads up!" dialog is probably shown until the user has acknowledged it once. Probably limited to administrators.

Who uses it and how

Developers and administrators pick a theme and a file, edit its content in the code area and press "Update File"; the screen itself advises using other tools for CSS changes.

Main features

  • Choosing which installed theme to edit
  • Browsing the theme's files and folders
  • Editing a file in a code editor with line numbers and syntax highlighting
  • Saving with "Update File"
  • Safety warning dialog and advisory notices

Usage flow

  1. Open "Tools" > "Theme File Editor".
  2. Read the "Heads up!" dialog and press "I understand" (or "Go back" to leave).
  3. Optionally choose another theme in "Select theme to edit:" and press "Select".
  4. Pick a file in "Theme Files".
  5. Edit the content and press "Update File".

Variants and business rules

States and variants

Captured with the "Heads up!" dialog open over style.css of the active theme. The editor after acknowledging the dialog, other files, expanded folders, the success or error message after "Update File" and an inactive theme (whose heading would probably lack "(active)") were not captured.

Business rules and constraints

Direct edits to theme files may be lost when the theme is updated and could break the site (stated in the dialog). For this theme a minified style.min.css is what visitors normally receive, so edits to style.css may have no visible effect (stated in the notice and the file's own comment).

Open questions

  • Whether acknowledging the dialog is remembered per user.
  • Which file types are editable and whether files in sub-folders can all be opened.
  • What validation runs on "Update File".
  • Whether this editor is disabled in production configurations.
