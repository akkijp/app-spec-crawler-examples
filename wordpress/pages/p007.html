About this screen

Purpose

Adds new files to the Media Library so they can be used in posts and pages.

Shown when

Shown when "Media" > "Add Media File" is chosen in the side menu, or "New" > "Media" in the admin toolbar (/wp-admin/media-new.php). Probably limited to users who may upload files.

Who uses it and how

Authors and editors drag files from their computer onto the drop zone or pick them with "Select Files"; several files can probably be uploaded at once.

Main features

  • Drag-and-drop upload
  • File selection through "Select Files"
  • Fallback "browser uploader"
  • Display of the maximum upload size

Usage flow

  1. Open "Media" > "Add Media File".
  2. Drag files onto the drop zone, or press "Select Files" and choose them.
  3. Wait for each upload to finish (progress and results are probably listed under the drop zone).
  4. Go to the Media Library to see the uploaded files.

Variants and business rules

States and variants

Only the initial empty state with the multi-file uploader was captured. Upload progress, the list of uploaded files with edit links, error messages and the browser-uploader variant were not captured.

Business rules and constraints

Uploads are limited to 2 MB per file on this site (stated on screen).

Open questions

  • Which file types are accepted.
  • What is shown after a successful upload and whether details can be edited from here.
  • The exact error shown for an oversized or disallowed file.
