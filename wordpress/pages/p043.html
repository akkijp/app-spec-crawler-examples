About this screen

Purpose

Lets an administrator pull in the plugins they marked as favorites on WordPress.org, a shortcut for people who set up many sites with the same plugins.

Shown when

Shown when the "Favorites" tab is clicked (URL `tab=favorites`). The search box of the other tabs is not shown here. Shown to the logged-in user "demo" (an Administrator); whether lower roles can open it was not captured.

Who uses it and how

A site administrator who has a WordPress.org account with favorite plugins.

Main features

  • Look up favorite plugins by WordPress.org username
  • Install a favorite with "Install Now" (inferred, after lookup)

Usage flow

  1. Click the "Favorites" tab.
  2. Enter a WordPress.org username.
  3. Press "Get Favorites".
  4. Install plugins from the resulting list (inferred).

Variants and business rules

States and variants

Only the initial empty form was captured. The result list, an unknown username and a user without favorites were not captured.

Business rules and constraints

Favorites are public per WordPress.org username, since only the username is requested.

Open questions

  • Is the entered username remembered for the next visit?
  • What message appears for a username that does not exist or has no favorites?
