About this screen

Purpose

Shows what most WordPress sites use, as a safe starting point when choosing well-known plugins such as form, SEO or cache plugins.

Shown when

Shown when the "Popular" tab is clicked (URL `tab=popular`). Shown to the logged-in user "demo" (an Administrator); whether lower roles can open it was not captured.

Who uses it and how

A site administrator looking for widely used plugins; they page through the list or go straight to search.

Main features

  • Browse the directory by popularity
  • Page through 2,076 pages
  • Activate an already installed plugin from its card
  • Search the directory
  • Install with "Install Now"

Usage flow

  1. Click the "Popular" tab.
  2. Scroll through the cards or move to the next page.
  3. Open "More Details" for candidates.
  4. Press "Install Now" (or "Activate" for an installed plugin).

Variants and business rules

States and variants

Captured on page 1 only. Because the screen is very tall, the capture is split into the initial image and s02 (the bottom). Cards differ by install state ("Install Now" / "Activate") and by compatibility line.

Business rules and constraints

The button on a card reflects whether the plugin is already installed on this site. The compatibility line compares the plugin's tested version with the site's WordPress version.
