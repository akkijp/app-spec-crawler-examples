Connectors

The "Connectors" screen under "Settings": one place to hold the API keys and credentials that plugins share. On this demo site it lists four connectors — "Akismet Anti-spam", "Anthropic", "Google" and "OpenAI" — none of them set up.

About this screen

Purpose

Lets an administrator configure an external service once and have every plugin use it, as the screen's own description says: "Configure once and use everywhere."

Shown when

Shown from Settings › Connectors. The capture shows the fully drawn screen: the description, the AI plugin banner and four connector cards. Unlike the other settings screens it has no "Help" tab.

Who uses it and how

Administrators setting up spam protection or AI text and image generation for the site.

Main features

  • See which external services can be connected
  • Install or activate a connector
  • Jump to the plugin directory to look for more connectors

Usage flow

  1. Open Settings › Connectors
  2. Find the service you want to use
  3. Press "Install" or "Activate" on its card
  4. Enter the credentials the connector asks for (not observed)

States and variants

Business rules and constraints
