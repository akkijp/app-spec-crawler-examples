About this screen

Purpose

Lets the administrator judge a plugin (what it does, compatibility, ratings) before installing or activating it. It is reached from "More Details" or "View details" links and normally appears as an overlay on the calling screen.

Shown when

Shown when a plugin's "More Details" / "View details" link is used; the URL carries `tab=plugin-information` and the plugin slug. It was captured as a standalone page, so the admin header and side menu are absent.

Who uses it and how

A site administrator reading up on a plugin before pressing "Install Now" or "Activate".

Main features

  • Read a plugin's description, installation notes, changelog and reviews
  • Check version, requirements and compatibility
  • See rating distribution and contributors
  • Activate (or install) the plugin from the footer

Usage flow

  1. Click "More Details" on a plugin card or "View details" in the plugin list.
  2. Read the description and check the requirements in the right column.
  3. Switch to "Installation", "Changelog" or "Reviews" as needed.
  4. Press the footer button to activate (or install) the plugin, or close the window.

Variants and business rules

States and variants

Only the "Description" section of one installed-but-inactive plugin was captured. The other three sections, the variant for a plugin that is not installed, and the variant for an active plugin were not captured.

Business rules and constraints

The footer action depends on the plugin's state on this site: probably "Install Now" when absent, "Activate" when installed and inactive.

Open questions

  • What does the footer show for a plugin that is already active?
  • Is a warning shown when the plugin is untested with the site's WordPress version?
