About this screen

Purpose

Used to back up content or move it to another WordPress installation, where it is read by the Import function. It is "Tools" > "Export" in the side menu.

Shown when

Opened from "Tools" > "Export". Shown to the logged-in user "demo" (an Administrator); whether lower roles can open it was not captured.

Who uses it and how

A site administrator preparing a migration or a content backup.

Main features

  • Export all content as one XML (WXR) file
  • Export only posts, pages or media
  • Download the export file

Usage flow

  1. Open "Tools" > "Export".
  2. Choose what to export.
  3. Press "Download Export File" and save the XML file.
  4. On the target site, load the file with the WordPress importer.

Variants and business rules

States and variants

Captured with "All content" selected. The extra filters for "Posts", "Pages" and "Media" were not captured.

Business rules and constraints

Export is read-only for the site: it produces a file and leaves content unchanged (inferred). The intro does not mention users, settings, plugins or themes as part of the file.
