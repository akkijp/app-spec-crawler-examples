About this screen

Purpose

Informs site owners of the licensing terms of the software they run. It has no function for running Acme Journal.

Shown when

Shown to any logged-in user who opens it from the WordPress logo menu in the toolbar ("About WordPress") or from another About tab; the side menu has no item for it, so no menu entry is highlighted.

Who uses it and how

Any administrator or editor of the site who wants background on the WordPress software itself; it is read once in a while, not used in daily work.

Main features

  • Explanation of the four freedoms of the GPL
  • Guidance on the WordPress trademark
  • Guidance on plugin and theme licensing

Usage flow

  1. Open "About WordPress" and choose the "Freedoms" tab.
  2. Read the four freedoms and the licensing advice.
