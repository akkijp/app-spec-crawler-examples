About this screen

Purpose

Lets an administrator maintain other people's accounts: change their role, correct name or email, set a password or send a reset link. It is reached from the user list, not from the side menu.

Shown when

Opened from a username or "Edit" link on p015 Users (URL carries the user's id). The side menu keeps "All Users" highlighted. Shown to the logged-in user "demo" (an Administrator); whether lower roles can open it was not captured.

Who uses it and how

A site administrator changing someone's role or helping a user who lost access.

Main features

  • Change a user's role
  • Edit another user's name, nickname, display name, email and website
  • Set the user's personal admin options
  • Set a new password for the user
  • Send a password reset link
  • View the user's public page ("View User")

Usage flow

  1. On p015 Users, click the username or "Edit".
  2. Change the role or other details.
  3. Optionally press "Set New Password" or "Send Reset Link".
  4. Press "Update User".
  5. Return to the user list.

Variants and business rules

States and variants

Captured for one user with the role Author on a non-HTTPS local site. Success and error messages, the "New Password" row with its password field and editing a user with another role were not captured. The "Profile Picture" area is blank in the capture, without the Gravatar link seen on p017. The "New Password" row of "Account Management" is not visible in the capture.

Business rules and constraints

Only someone allowed to manage users can reach this screen (inferred). Usernames are permanent. Sending a reset link does not change or invalidate the current password, according to the on-screen note.

Open questions

  • The heading and display name show "Sample Author" while the "Name" column on p015 shows "—"; where is that display name stored?
  • Can an administrator end another user's sessions from this screen (no "Sessions" row is shown)?
  • What happens to a user's access when "— No role for this site —" is chosen?
  • The "New Password" row ("Set New Password") was not visible in this capture; how it looks and behaves on this screen is unconfirmed.
