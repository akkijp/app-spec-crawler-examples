About this screen

Purpose

The starting point for migrating posts and comments from another blog platform or another WordPress site. It is "Tools" > "Import" in the side menu and the counterpart of p020 Export.

Shown when

Opened from "Tools" > "Import". Shown to the logged-in user "demo" (an Administrator); whether lower roles can open it was not captured.

Who uses it and how

A site administrator moving content into the site, typically once during setup or migration.

Main features

  • List available importers
  • Install an importer
  • View importer details
  • Search the plugin directory for other importers

Usage flow

  1. Open "Tools" > "Import".
  2. Find the source system in the list.
  3. Click "Install Now" for it, then start the importer (inferred).
  4. Follow the importer's own steps, such as uploading an export file (not captured).

Variants and business rules

States and variants

Captured with no importer installed. The state after installation (a run link) and the importers' own screens were not captured.

Business rules and constraints

Importers are separate plugins that must be installed before use. The "WordPress" importer reads the export file produced by p020 Export, according to the texts on both screens.

Open questions

  • What does a row show after its importer is installed?
  • Is installing an importer limited to administrators?
