About this screen

Purpose

Acknowledges the people and open source libraries behind the WordPress software. It has no function for running Acme Journal.

Shown when

Shown to any logged-in user who opens it from the WordPress logo menu in the toolbar ("About WordPress") or from another About tab; the side menu has no item for it, so no menu entry is highlighted. The list of people is probably fetched from WordPress.org, so it may be reduced when the site cannot reach it.

Who uses it and how

Any administrator or editor of the site who wants background on the WordPress software itself; it is read once in a while, not used in daily work.

Main features

  • Grid of noteworthy contributors with photos and roles
  • Full list of core contributors for the release
  • List of external libraries
  • Invitation link to contribute

Usage flow

  1. Open "About WordPress" and choose the "Credits" tab.
  2. Scroll through the featured contributors and the full list.
  3. Scroll to the bottom for "External Libraries" when checking which third-party components are bundled.
