About this section

Role in the business

Where the people who run the site write and publish content, moderate comments, manage users, and configure the site.

Screens included and how they divide the work

The Dashboard (p001) is the entry point. Content screens come in list → edit pairs: Posts (p003) → Edit Post (p035), Categories (p004) → Edit Category (p036), Tags (p005) → Edit Tag (p037), Users (p015) → Edit User (p045). Add Plugins (p014) has one screen per tab (p039–p044). Settings is a row of independent forms (p025–p032). The About WordPress pages (p033, p034, p048–p050) are static information.

Navigation within the section

Move between areas with the left-hand menu. Within an area, a list row's title leads to its edit screen, and submenu items or tabs switch between sibling screens.

Permissions and visibility

Requires a logged-in account. The capture shows the administrator's view.
